FileLLM

Ask me about your files in plain English. I'll pick the tools, run them against your actual disk, and show you every step in the panel on the right.

I can read inside .docx, .pdf, .xlsx and .pptx files, filter by real modification dates, and find byte-identical duplicates — the things File Explorer search handles badly or not at all.

I can't delete or move anything myself. I can only propose changes; you approve them in the Approvals tab, deletions go to the Recycle Bin, and moves can be undone.

Every model turn, tool call and result appears here as it happens.
The raw HTTP traffic to the model — full request and response bodies, status codes, latency and token counts.
Proposed file changes land here. Nothing runs until you approve it.
Applied changes can be reversed from here.
